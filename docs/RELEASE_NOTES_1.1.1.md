# 大学生小帮手 1.1.1 更新说明

以下为相对 1.0.0 的累计变化。Android 8.0 及以上；versionCode 26。

- 优化文字稳定确认：减少换行、OCR 行号和选项标签格式差异导致的反复等待，确认回调被节流或异步识别打断后继续调度；仍检查真实题干、选项与题型变化。
- 改善下一题监测：旧导航核验等待不再阻塞已变化页面进入识题，保留画面新鲜度、题目去重及动作核验。
- 悬浮助手的小水怪常驻，识题、分析和下一题阶段显示加载环与状态标记。
- 答案改为自动展开的紧凑聊天气泡，支持长文滚动，按答案长度调整停留时间，触摸或复制后延长；主动关闭后立即恢复识题。答案与小复制、关闭图标对齐。
- 填空题、简答题完整答案自动复制到剪贴板，仍保留手动复制。
- 新增可选2号桌宠：沃特森抱着小水怪，待机循环、点击互动一次后恢复待机；点击沿用现有手动切到下一题功能，拖动不触发点击。桌宠缩为48dp，开关整合到首页主助手按钮旁。
- 默认配色改为象牙白；桌宠介绍问号缩小并与文字对齐，移除首页桌宠开关被裁切的光晕。
- 桌宠介绍、关于应用的协议/隐私/用途声明/许可全文，以及应用内开始屏幕共享说明弹窗，统一为主题配色与圆角样式；长文可滚动。后续系统屏幕共享授权界面仍由 Android 管理。
- 首页常驻首次使用教学、DeepSeek API 获取与配置教程，以及自动识别/自动选择功能公告。
- 我的页面新增赞助支持，展示本地赞赏码，每次打开随机显示本地祝福语。
- 更新用途声明、隐私政策及用户协议至修订4，说明剪贴板与赞助展示的数据处理。

自动选择答案仍需有人看护，不建议挂机刷题。仅限个人学习研究，严禁考试作弊及非法用途，AI答案请独立核验。
