大学生小帮手隐私政策

个人信息处理者/运营者：Cenbyte；联系邮箱：Cenbyte.dev@outlook.com。
官方公开源码仓库：https://github.com/Cenbyte/ScreenQA 。本政策说明本应用提供服务时的信息处理及用户权利。

1. 功能与使用前告知

本应用仅供个人学习研究，严禁用于线上考试等违规场景。首次进入前显示用途声明，并提供本政策与用户协议全文；拒绝可退出。应用不要求注册账户，没有开发者运营的账户、支付或题目上传服务器。AI 请求直接发往你配置的接口；第三方 SDK 可能存在下述诊断联网行为。因此本应用并非完全离线工具。

首次确认后才进入功能页面并启动应用自身的常规状态和日志初始化。此确认不包含屏幕共享、无障碍、Root 等系统权限授权；第三方 SDK 的启动阶段初始化由 Android 及 SDK 机制控制，SDK 可能在应用启动阶段初始化，相关诊断联网行为详见第三方 SDK 与服务一节。

2. 屏幕、识别与 AI 请求

你主动授权屏幕共享并启动助手后，屏幕图像在运行中供本地 OCR 处理；已授权的无障碍能力可读取目标页面的文字、选项、输入框及必要位置，帮助定位学习材料与执行明确开启的辅助操作。可能读到当前屏幕上的其他内容，请关闭无关窗口，不在敏感页面启动助手。可随时暂停、停止屏幕共享或撤销系统权限。

当前应用代码不会将屏幕图像作为 AI 请求附件上传，而是发送识别后的文字：本地定位成功时提交题干、选项；需要 AI 定位时可能提交页面文字、行号与归一化纵向位置；手动选区提交选区文字。模型、提示词、生成参数与 API Key 通过 HTTPS 发送给所选接口。服务商还会自然获取请求的 IP、时间及协议元数据。AI 服务返回参考内容、错误和实际用量信息。

默认服务为 DeepSeek；选择自定义 HTTPS 接口时，接收方变为该地址对应服务商。应在切换前核实服务商身份、政策、保存期限和费用；可能涉及境外接收方时，不要将首次确认误认为已完成法律要求的跨境事项。不得向未知接口提交敏感信息或无权提供的内容。

屏幕帧主要在运行内存中处理；本应用没有自动将整屏截图保存至相册或开发者服务器的功能。诊断日志可能包含部分识别文字、题目和答案，不能笼统承诺相关内容不会落盘。

3. 本机保存的信息与期限

- API Key：由你输入，使用 Android Keystore 支持的 AES/GCM 加密后保存在应用私有目录，用于向你选择的 AI 接口鉴权。设置保存失败时应检查页面提示，不承诺任何设备或攻击条件下的绝对安全。
- 设置：主题、模型、接口、授权相关选项、辅助操作开关、声明修订号及确认时间，存于本机 SharedPreferences，直至你修改、清除应用数据或卸载。
- Token 用量：保存最近有效请求、今日和累计真实用量；开发者版另有分类明细、SHA-256 题标识、自设单价预算，最近明细最多 500 条、每日分类汇总保留最近 31 天，累计数据保留至清除。题标识哈希是去标识处理，不保证任何条件下都无法关联。
- 诊断日志：用户版默认关闭，开发者版默认开启，已有显式设置保留。启用时记录运行状态、设备系统版本及部分题目/答案片段；私有 Q&A 目录按每文件约 256 KB、最多 8 个、总量约 2 MB 轮换。可停止记录、清除日志或自行导出；源码设计不向日志写入 API Key，但导出前仍应自行检查是否包含敏感内容。
- 导出文件：仅在你主动使用系统文件选择器导出日志或用量时，写至所选位置。由你保管和删除，不随卸载自动删除。本应用不自动上传这些文件。

本应用关闭 Android 自动备份。清除应用数据或卸载会清除本机应用私有数据；已经发送的 AI 请求、SDK 诊断数据和自行导出的副本不会因此被远程删除。

4. 第三方 SDK 与服务

Google ML Kit（打包依赖 com.google.mlkit:text-recognition-chinese:16.0.1）用于设备上中文 OCR。Google 官方说明输入图片和识别结果由 ML Kit 在本机处理，不由 ML Kit 上传给 Google；但 SDK 可联系 Google 服务器并发送诊断/使用指标，例如设备型号与系统、应用包名与版本、安装级标识、性能、配置、输入输出大小、初始化事件和错误码。该 SDK 的诊断联网与本机图片识别是不同的数据处理环节。接收方为 Google；境外处理、保留期限及权利行使适用其政策，同时发布者须履行自身法定义务。

- ML Kit 条款与隐私：https://developers.google.com/ml-kit/terms
- ML Kit 数据披露：https://developers.google.com/ml-kit/android-data-disclosure
- Google 隐私政策：https://policies.google.com/privacy

液态玻璃 UI 库 QWEA0/Liquid-Glass-Android 用于绘制背景效果。当前封装关闭传感器高光；未在应用代码中给它设置账号或上传接口。Kotlin 运行时及其他传递依赖用于本地运行；其来源和适用许可可在“关于应用 → 开源信息”查看。

DeepSeek 或自定义 AI 服务依据各自协议处理请求。默认接口 https://api.deepseek.com/chat/completions。DeepSeek 政策入口：https://cdn.deepseek.com/policies/zh-CN/deepseek-privacy-policy.html 。本应用不控制第三方保存期限，第三方保存和使用请求数据的规则由其政策规定。请核对当前服务条款；删除或查询已发送的数据应通过该服务商渠道办理。

5. 权限与关闭方式

- 网络：发送你主动触发的 AI 请求，以及第三方 SDK 的必要联网。
- 悬浮窗：显示助手和参考内容，可从系统设置撤销。
- 屏幕共享及前台服务：在你确认系统授权后读取当前屏幕，运行时持续通知，可在通知或助手中停止。
- 通知：展示运行状态与停止入口，可按系统规则关闭。
- 无障碍：你主动在系统启用后读取学习页面节点；仅在对应辅助操作开启时选择、填写或翻页，自动下一题单独控制。可从系统撤销。
- Root：默认关闭的可选能力，设备权限管理器单独授权；可在应用关闭或从权限管理器撤销，不替代屏幕共享及无障碍授权。

不申请定位、通讯录、相机、麦克风或全盘文件读取权限。与系统/第三方 SDK 合并的最终权限清单应以正式构建 Manifest 为准，新增权限应相应告知。

6. 权利、未成年人及更新

你可修改设置、关闭功能、撤销系统权限、停止并清除日志、清除应用数据或卸载；访问、更正、删除、撤回同意及其他法定权利请求可发送至 Cenbyte.dev@outlook.com。无账户的本机工具不因此免除个人信息处理者的义务。撤回某项授权后，相应功能将不能继续使用；已依法进行的处理和第三方数据应分别处理。

本应用面向具有自主判断能力的个人学习者，不面向不满十四周岁儿童提供专门服务。其他未成年用户应在监护人指导下使用，不提交儿童或他人的敏感个人信息。若未来面向儿童提供服务，应另行落实相应规则。

政策重大变更会更新文档修订号并按实际变更重新告知、必要时重新确认。发生安全事件时，运营者应依法处理并履行通知、报告等义务；可通过上述邮箱联系运营者处理相关事项。
