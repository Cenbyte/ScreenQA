1. 产品与适用范围

大学生小帮手是个人学习研究工具，可识别经授权展示的学习材料、请求 AI 解析、展示和复制参考内容。部分可选辅助操作可选择或填写内容、翻页。所有能力仅可用于合法、有权限的学习练习或技术研究场景。没有学校、考试机构或平台对本工具的授权或推荐关系。

阅读本文及隐私政策后，自愿勾选并进入应用表示你确认用途限制及相关数据处理说明。拒绝可退出。首次确认不意味着你授予了屏幕共享、悬浮窗、无障碍或 Root 权限；每项权限仍由系统及相应设置单独控制。

2. 禁止用途与学术诚信

严禁将本应用用于线上或线下考试、测验、考核中的违规答题、代考、协助作弊、组织作弊、规避监考，或用于其他要求独立完成而禁止外部辅助的任务。严禁非法获取、出售、提供、传播未公开试题及答案。不得以“研究”“学习”名义规避上述限制。

禁止未经授权访问、读取或操控他人系统，禁止窃取个人信息、侵害隐私和知识产权、绕过平台访问限制，禁止用于任何其他违法犯罪行为。你应遵守法律法规以及学校、考试机构和平台规则。存在规则不明的情形时，请先向规则制定方确认许可，未确认前不要使用本应用参与相关任务。

技术上具有读取和操作界面的能力不代表获得相关系统的许可。本应用没有可靠识别所有考试场景的机制，用途声明也不构成已经从技术上杜绝滥用的承诺。

3. AI 内容、辅助操作及费用

AI 可能生成错误、遗漏、虚构或不适合具体场景的内容，仅供学习参考。请独立思考、核验信息，不以输出作为医学、法律、投资等重大决定的唯一依据，不承诺正确率、通过率或不间断服务。

辅助自动执行总开关默认关闭，自动下一题为独立开关。启用可选操作前应确认目标页面、权限和用途；可随时暂停或关闭。Root 权限影响设备安全，仅在理解风险时使用，不绕过系统授权。

你自行配置 AI 服务账户、接口和 API Key。第三方服务可能按请求产生费用，由你与该服务商的约定决定。本应用仅统计收到的实际 Token 数据，自设单价预算不等于服务商账单；本应用没有充值、余额或积分扣费系统。

4. 内容权利与源码许可

你应确保有权处理学习材料及向所选 AI 服务提交内容，不提交敏感个人信息、保密材料、未公开试题或侵权内容。你对自身输入及使用行为依法承担相应责任。

工程源码使用随仓库附带的 LICENSE 所载许可；第三方 SDK、字体、图像及其他素材按各自权利和许可使用。本协议不缩减开源许可证已经授予的权利。图标由 Cenbyte 原创并提供用于本项目公开发布。

5. 数据与权限

屏幕内容、AI 接口请求、日志与本地设置的处理详见隐私政策。请使用应用和系统提供的暂停、停止、撤销权限及清除数据功能。协议确认不代替法律要求的特定数据处理告知或单独同意。
