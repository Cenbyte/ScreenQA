# 大学生小帮手 1.1.0

Android 8.0 及以上；versionCode 25；用户包 cn.screenqa.lite，开发者包 cn.screenqa.lite.dev / 1.1.0-dev。

- 小水怪在加载和答案状态保持显示，进度环在角色外围转动。
- 答案以带小尾巴的聊天气泡从角色旁边快速展开；优先右侧，空间不足时改放左侧或上下方。宽高随内容调整，过长内容可滚动，避开系统栏。
- 短答案至少停留 10 秒，完整填空/简答至少 20 秒；按字数延长，最长 90 秒。手指触摸时不收起，松手或复制后重新计时。阅读期间暂缓新题识别，可关闭气泡立即继续；收起后点击角色重新查看。
- 已明确开启的辅助执行和自动下一题继续遵循原有保护逻辑，自动导航可能提前关闭气泡。
- 完整填空/简答答案自动复制到系统剪贴板；不自动复制条件不完整的结果。保留较小的手动复制图标与长按文本选择。
- “我的 → 赞助支持”原样展示用户提供的微信赞赏码，内置 16 条祝福语，每次打开随机选择且不连续重复。赞助自愿，不影响现有功能；页面没有新增网络请求或支付回调。

构建和 JVM 测试不能替代设备实测；仍需检查悬浮窗边缘位置、长答案滚动、自动复制与微信识别赞赏码。仅限个人学习研究，严禁考试作弊及非法用途。
