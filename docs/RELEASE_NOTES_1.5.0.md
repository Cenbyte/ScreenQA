# 大学生小帮手 1.5.0

versionCode: 36

- 新增在线知识库下载和 ZIP 安装，在本地建立全文检索索引。AI 作答前最多整理 5 条相关题目与知识点作为额外参考，并限制参考长度；可自由关闭，参考资料仍需核验。
- 安装显示真实六步进度：下载、校验、解压、导入并建立索引、整理并检查索引、完成安装。失败时显示发生步骤、原因与重试入口。
- 首页知识库与 2 号桌宠开关统一放在“开启悬浮助手”按钮下方，同排对齐并收紧留白。问号可查看用途、知识库加载结果和数据量。
- 知识库尚未安装、被禁用或索引无法读取时拒绝开启并说明原因；2 号桌宠权限不足时无法开启，返回应用后复查权限。
- 精简知识库管理页，将文件及收件箱安装折叠到“其他方法”；支持知识包启用、禁用和删除。
- 删除首次知识库配置弹窗，改为顶部滚动字幕提醒；修复内置蓝奏云文件弹窗顶部空白。

正式包包名为 `cn.screenqa.lite`，沿用原发布证书。知识包须单独下载或导入，不随 APK 或源码包内置。本地参考可能存在噪声或不完全匹配，不承诺答案正确率。
