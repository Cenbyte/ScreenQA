# 本地知识库

知识库在 AI 作答前检索相似题目和知识点，提供简洁参考资料。参考可能不完全匹配，仍应独立核验；关闭后使用原有 AI 作答流程。

## 安装与开启

1. 在设置中打开“知识库管理”，点击“在线获取知识库”。内置网页自动输入公开提取码，失败时可手动输入。
2. 点击知识包下载，等待六步安装完成；也可在“其他方法”中从文件或收件箱安装 ZIP。
3. 启用所需知识包，再开启总开关。首页问号可检查加载结果。

安装在后台执行，显示真实阶段及进度。无法计算百分比时显示不确定进度，失败保留当前步骤与原因。未安装、全部禁用或索引无法读取时，总开关开启失败并提示处理方法。

## 数据与检索

知识包包含 manifest.json 和 data/ 下的 e_eval.jsonl、k12_kgraph.jsonl、k12_knowledge_points.jsonl、m3ke.jsonl。统一字段为 id、source、stage、subject、type、question、options、answer、explanation、knowledge、content，支持原始来源扩展字段。记录数及摘要等元数据需与 manifest 一致。

ZIP 验证、路径检查和流式读取在安装时完成。文件、解压内容和索引保存在应用私有目录，无需公共下载目录或全盘存储权限。正常做题只查询持久索引，不重新扫描 JSONL。

运行时优先探测 FTS5，不可用时使用系统 FTS4 与 BM25F。相同题干及选项优先，相关知识点其次；关系记录保留但不作为普通题目参与主检索。最多取 5 条参考，整理后的上下文最多 4,000 字符，并向 AI 说明资料可能有噪声、不应无条件照抄。

知识包可以分别禁用或删除。删除同时清理对应索引、解压文件及 ZIP。API 请求可能包含检索参考片段；单纯下载、安装和查看本地检索结果不调用 AI。
