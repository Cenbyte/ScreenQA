# 大学生小帮手 1.2.2

这次更新完善了横屏 Pad 布局、悬浮助手材质和连续识题流程，同时修复了底部导航的显示问题。

- 横屏宽大于高时启用 Pad 布局，导航移到右侧。首页、设置、我的统一为双列纵向排列，各页面互不露出；手机竖屏保持原布局。
- 首页常驻版本与主控制台、公告、首次使用教学和 DeepSeek API 配置教程，移除堆叠卡片及横滑翻页。
- 1 号悬浮助手改为半透明磨砂背景，小水怪保持原图；修正状态文字被圆形边缘裁切的问题。
- 答案窗改为扁长磨砂聊天气泡，增加小字号题目摘要和醒目的大字号答案。20 字以内题干直接展示，长题优先显示摘要。
- 得出答案后不再等待阅读倒计时结束才继续寻找下一题：关闭辅助自动执行时等待 0.4 秒，开启对应题型执行时等待 0.2 秒安排扫描。实际定位时间还受屏幕稳定性、OCR 和接口处理影响。
- 下一题定位成功前保留旧答案窗口，定位到不同题目后再关闭；关闭辅助执行时仍只识别和显示答案。
- 首页自动检查 GitHub 最新正式版，提供重新检查和跳转更新入口。
- 底部 Dock 横滑即时切页，修正液态玻璃上沿黑色撕裂和选中胶囊遮挡标签的问题。
- Dock、更新按钮、助手开关、桌宠开关及赞助入口增加分级触感反馈，遵循系统触感设置。

支持 Android 8.0 及以上，正式包名 `cn.screenqa.lite`，沿用已有发布证书。Android 12 及以上且系统支持时启用跨窗口背景模糊，不支持时使用材质回退。

仅限个人学习研究；参考答案请自行核验，辅助自动执行默认关闭。严禁用于考试作弊及任何非法用途。
