# 1.2.2 更新说明

- 首页自动检查 GitHub 最新正式版，显示最新版本状态、网络失败说明和重新检查入口；发现新版本可跳转对应 Release。
- 更新卡片采用紧凑的标题与版本说明，按钮与开启悬浮助手保持一致。
- 底部 Dock 切换、更新按钮、悬浮助手开关、首页2号桌宠开关及赞赏页面入口增加短促震动反馈。
- 悬浮助手反馈较强、Dock 与更新/赞赏入口中等、2号桌宠开关较轻；遵循系统触感反馈开关，实际手感由设备马达决定。

版本：1.2.2 / versionCode 28；开发版显示 1.2.2-dev。

- 底部 Dock 支持横向滑动即时切换：手指进入哪个标签，页面就立即切过去并提供中等震动，无需松手。
- 调整液态玻璃 Dock 的边缘折射与背景刷新，针对切换到“我的”时上沿黑色撕裂进行修正。
- 修正选中玻璃胶囊遮挡图标和文字的问题，导航标签保持在玻璃上方清晰显示。

发布标签：v1.2.2

versionCode: 28

支持 Android 8.0 及以上。本版沿用正式用户版包名与发布签名；开发者测试包独立安装。构建、JVM 回归及 Lint 检查通过，最新 Dock 显示改动仍需原设备验收。
